This repository contains a PDF map titled Location_Map.pdf, showcasing the geographical extent of the Nilwala River Basin, created for a university project. The high-resolution map, originally developed using GIS software, highlights key spatial features of the basin but is provided in PDF format to optimize storage and accessibility due to the large file sizes of native GIS formats. Ideal for reports, presentations, or reference in studies related to the Nilwala River Basin, the map can be viewed using any PDF viewer. For detailed geospatial analysis, original GIS data may be available upon request, subject to file size constraints.
